# MAC_MPP_Viewer
Solution for reading and viewing M365 Microsoft Project files on a Mac

===
1.  Download ProjectLibre from https://projectlibre.com
2.  make sure you have homebrew installed.
3.  run:   brew install openjdk 
4.  run the install-mpxj.sh script found here, to install the conversion library.
5.  To use run the script created in the above step: ./mpxj-convert.sh input.mpp output.xml
6.  Open output.xml in ProjectLibre
